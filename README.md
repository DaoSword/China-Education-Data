## 简介 Introduction

Collection of China's educational data and information, including colleges, high schools, midddle schools, education groups, etc.

本项目致力于收集和整合中国教育领域的各类数据和信息，计划收集内容包括高等教育、中等教育、教育集团、校外教培等各类院校机构的信息，以及教育行业的宏观数据等。
